# DataSense AI: Intelligent CSV Analysis Agent

An AI-powered agent that analyzes any CSV file and turns it into insights in seconds. Submitted to the **Microsoft Agents League Hackathon 2026** (2,464+ participants).


## Features
- Automated data profiling (shape, data types, summary statistics)
- AI-generated insights from the uploaded dataset
- Missing-value detection
- Correlation heatmaps
- Distribution plots

## Tech Stack
Python, Streamlit, Pandas, Matplotlib, Seaborn, Azure AI, GitHub Copilot

## Run Locally
1. Clone the repo
   git clone https://github.com/Pawan07099/[repo-name].git
   cd [repo-name]
2. Install dependencies
   pip install -r requirements.txt
3. Run the app
   streamlit run [app.py]

## How It Works
1. Upload a CSV file
2. The app profiles the data and flags missing values
3. It generates plots and AI-written insights
